# 🎂 生日在圆周率第几位？ v1.0.0

查一查你的生日，藏在 π 的小数点后第几位。

---

## 📥 下载哪个？

| 文件 | 大小 | 说明 |
|---|---|---|
| **`PiBirthdayWeb.exe`** | 23 MB | **推荐** — 网页版界面（深色渐变 + 动效），功能最完整 |
| `PiBirthday.exe` | 19 MB | 桌面版（tkinter），单文件 |
| `PiBirthdayCLI.exe` | 19 MB | 命令行版 |
| `pi_1b.pack` | 449 MB | **10 亿位离线数据包**（可选，强烈建议） |

**双击即用** —— 不需要装 Python，也不需要联网。

### ⚠️ 两个注意事项

**1. Windows 提示「未知发布者」**

因为没买代码签名证书（个人项目）。点「更多信息」→「仍要运行」即可。

**2. 网页版需要 WebView2 运行时**

Win10/11 和 Edge 自带，一般无需额外安装。若提示缺失，去
[微软官网](https://developer.microsoft.com/microsoft-edge/webview2/) 装一下（免费，约 2 MB）。

## 🚀 怎么用

### 命令行

```bat
:: 查生日（自动逐级搜索）
PiBirthdayCLI.exe 1990-01-01

:: 机器可读输出
PiBirthdayCLI.exe 1990-01-01 --json

:: 查看环境与数据源状态
PiBirthdayCLI.exe --info
```

退出码：`0` 找到 · `1` 没找到 · `2` 出错

### 图形界面

双击 `PiBirthdayWeb.exe`，选年月日，点「开始查找」。

## 📦 关于 10 亿位离线数据包

`pi_1b.pack` 放在 exe **同一个目录**即被自动识别，无需任何配置。

| 指标 | 实测 |
|---|---|
| 搜索范围 | 10 亿位 |
| 8 位生日命中率 | **99.99%** |
| 全扫耗时 | 冷缓存 6.7~22s / **热缓存 0.8~1.0s** |
| 内存占用 | **仅 41 MB**（与总位数无关） |

**为什么 449 MB 只占 41 MB 内存**：包格式是「每 100 万位一个独立 zlib 块 + 偏移表」，
查第 k 块只解压那一块（约 0.47 MB）。

**并行搜索**：8 线程并行解压+搜索。但「首次出现」不能谁先算完算谁 ——
所以是并行计算、**按块序号顺序消费结果**，命中即取消未开始的任务。

数据完整性已用 MIT 官方 md5 校验：`3901670f41a84174103bd6a8f07651c0`

## 💡 为什么我的生日找不到？

8 位数字在 π 中首次出现的位置服从均匀分布，命中率 = `1 - e^(-N/1e8)`：

| 搜索位数 | 命中率 |
|---|---|
| 1000 万（内置） | 约 10% |
| 1 亿 | 约 63% |
| **10 亿（离线包）** | **约 99.99%** |

**找不到是概率使然，不是程序问题。** 下载离线包即可解决。

## ✨ 特性

- 🔍 **五种格式一起查** — `YYYYMMDD`、`YYMMDD`、`MMDDYY`、`DDMMYY`、`MMDD`
- 📴 **纯离线可用** — 内置 1000 万位，不联网也能出结果
- 🧠 **内存优先** — 本地计算按可用内存自动规划，宁可慢也不 OOM
- ⚡ **多线程按块搜索** — 10 亿位全扫约 1 秒
- 🖥️ **三种界面** — CLI / 桌面 GUI / 网页版
- 📦 **机器可读输出** — `--json` + 语义化退出码
